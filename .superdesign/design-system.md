# AURA design system

## Product

AURA is a privacy-first Midnight survey workspace. Its strongest UX rule is honesty: wallets own proof authorization, server-generated values are reservations, and local demo state must never resemble a finalized chain result.

## Visual direction

Use the existing paper-and-garden style: a calm illustrated sky/river canvas behind crisp white cards, emerald primary actions, slate text, and compact monospace labels for network/protocol values. Preserve Plus Jakarta Sans/Inter for UI text and Fira Code for metadata. Keep the layout spacious, rounded, and highly legible; use dark panels only for code/circuit surfaces.

## Interaction rules

- Make environment, demo, reservation, and on-chain confirmation states visually distinct.
- Keep wallet action buttons primary and concise.
- Always show token/faucet guidance as contextual help, never as an unverified claim.
- Prefer single-column mobile stacks and two/three-column desktop card grids.
